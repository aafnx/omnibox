# OmniBox для LG webOS

Приложение для телевизора LG: одна кнопка будит OMNIBOX по Wake-on-LAN и переключает телевизор на его вход HDMI.

- **Пробуждение по сети.** Magic packet уходит на все широковещательные адреса сети телевизора и напрямую на IP устройства: три повтора, порты 9 и 7.
- **Переключение входа.** HDMI 1–4, по умолчанию HDMI 3.
- **Поиск устройств.** Приложение опрашивает подсеть телевизора `/24` и показывает включённые устройства с IP, MAC и именем. Имя берётся из NetBIOS для Windows или из DNS. Выбранное устройство подставляется в настройки.
- **MAC по IP.** Достаточно ввести IP и нажать «Найти MAC». Устройство в этот момент должно быть включено.
- **Проверка связи.** На главном экране видно, в сети устройство или нет.
- **Питание через WinCLI.** На главном экране есть кнопки «Сон», «Перезагрузить», «Выключить» и «Заблокировать». Перезагрузка и выключение спрашивают подтверждение. Команды выполняет агент [WinCLI](https://github.com/aafnx/win-cli) (`win --agent`) на OMNIBOX.
- **Запускать сразу.** При открытии приложение отправляет сигнал и через 1,5 секунды переключает вход. Чтобы остаться в приложении (например, зайти в настройки), нажмите любую кнопку пульта во время отсчёта.

Интерфейс собран по дизайн-системе OMNIBOX: тема `night`, шрифты лежат в приложении, интернет не нужен.

## Установка

Нужен включённый Developer Mode на телевизоре (приложение Developer Mode из LG Content Store).

**Через webOS Dev Manager.** Вкладка Apps → Install → выберите `com.omnibox.launcher_1.1.0_all.ipk`.

**Через webOS CLI:**

```sh
npm install -g @webos-tools/cli
ares-setup-device                         # один раз: IP телевизора, порт 9922, пользователь prisoner
ares-novacom --device tv --getkey         # один раз: Passphrase с экрана Developer Mode
ares-install --device tv dist/com.omnibox.launcher_1.1.0_all.ipk
```

## Сборка из исходников

```sh
./build.sh        # → dist/com.omnibox.launcher_<версия>_all.ipk
```

Для предпросмотра без телевизора откройте `app/index.html` в браузере. Приложение запустится в режиме «Предпросмотр» с примерами вместо ответов телевизора.

## Первый запуск

1. Включите OMNIBOX.
2. Откройте OmniBox на телевизоре. Откроются настройки.
3. Нажмите «Найти устройства» и выберите OMNIBOX. Другой вариант: введите IP и нажмите «Найти MAC».
4. Проверьте вход HDMI и нажмите «Сохранить».

Если нужно, вынесите приложение в панель запуска рядом с HDMI-входами.

## Питание: сон, перезагрузка, выключение

Нужен WinCLI 1.4 или новее на OMNIBOX.

1. **Агент.** На OMNIBOX выполните `win --agent` (локально или по SSH). Агент встанет в автозагрузку, откроет порт `7798` для локальной сети и покажет код из шести цифр.
2. **Сопряжение.** На телевизоре откройте Настройки → «Питание · WinCLI» → «Подключить» и введите код.
3. **Готово.** Статус агента виден на главном экране. Для повторного подключения (например, после сброса телевизора) получите новый код: `win pair`.

Телевизор хранит только выданный токен. Агент принимает команды только из локальной сети и только от сопряжённых устройств.

## Чтобы пробуждение работало

- **В BIOS/UEFI** включите Wake on LAN (у некоторых плат пункт называется «Power On By PCI-E»).
- **В Windows** раздел `wake-fix` этого репозитория настраивает сетевую карту так, чтобы она будила OMNIBOX только по magic packet.
- **Подключение.** OMNIBOX лучше держать на кабеле. Wake-on-LAN по Wi-Fi работает редко.
- **Состояние ПК.** Из сна и гибернации OMNIBOX просыпается надёжно. Из полного выключения — только если сетевая карта получает питание (в Windows для этого отключают «Быстрый запуск»).

## Устройство

```
app/                 веб-интерфейс (HTML/CSS/JS, ES5 для Chromium 53 на webOS 4.x)
  appinfo.json       id com.omnibox.launcher
  js/app.js          экраны, навигация пультом, вызовы Luna
  css/omnibox.css    токены и компоненты дизайн-системы
  fonts/             Michroma, Unbounded Light, Inter, JetBrains Mono (SIL OFL)
service/             фоновый JS-сервис com.omnibox.launcher.service (Node.js)
  service.js         wake, discover, resolveMac, probe, info,
                     agentInfo, agentPair, agentPower (HTTP к агенту WinCLI)
build.sh             сборка .ipk
```

Веб-часть webOS не умеет отправлять UDP, поэтому Wake-on-LAN, опрос сети и ARP-таблица живут в сервисе. Вход переключается системным вызовом `luna://com.webos.applicationManager/launch` с `id: com.webos.app.hdmi<N>`.

Настройки хранятся только в `localStorage` телевизора. В репозитории нет ни адресов, ни других личных данных.

## Если что-то не работает

| Что видно | Что сделать |
|---|---|
| «Сигнал не отправлен» / «Поиск не удался» | Не установлен сервис. Переустановите `.ipk` целиком, не только папку `app`. |
| Сигнал ушёл, OMNIBOX не просыпается | Проверьте Wake on LAN в BIOS и раздел `wake-fix`. Также убедитесь, что телевизор и OMNIBOX в одной подсети. |
| В поиске нет OMNIBOX | OMNIBOX выключен или спит: найти можно только включённое устройство. |
| «Агент WinCLI не запущен» | На OMNIBOX: `win --agent`. Если агент запущен, но не отвечает, проверьте правило брандмауэра «win-cli agent». |
| «Агент не узнал телевизор» | Подключение сброшено на ПК. Получите новый код (`win pair`) и подключите заново. |
| Приложение пропало | Истекла сессия Developer Mode (50 часов). Продлите её в приложении Developer Mode или автоматически через Home Assistant. |
